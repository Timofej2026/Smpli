### Syntax and Documention

## IMPORTANT!

- The language name is **smpli**.
- Brackets `()` must contain text/arguments.
- Curly braces `{}` are used to define block structures and scope.
- The `print()` command works exactly like in Python.

### Core Commands

| Command | Description |
| :--- | :--- |
| `start` | Start of the script. |
| `stop` | End of the script. |
| `scriptTag()` | Script tag/metadata. |
| `use()` | Import/use an engine or module. |
| `numVar=()` | Store a number. |
| `var()` | Store a letter/character. |
| `word()` | Store a string/word. |
| `()±()` | Mathematical operations and expressions. |
| `()=()` | Evaluates a numeric or string value. |
| `±()=()` | Concept of numbers or letters evaluation. |
| `whenPressed()Do()` | Triggers an action if a specific key is pressed. |
| `ccor()` | Set XYZ coordinates. |
| `sendMessage()To()` | Send a message to an object or system. |
| `givenMessage()` | Receive/get the sent message. |
| `check()` | Check/verify a condition. |
| `if` | Conditional check (if). |
| `then` | Execution block condition (then). |
| `else` | Alternative execution block (else). |
| `do` | Action execution block (do). |
| `toDo()` | Explicit block definition for what to do. |
| `alert()` | Show a notification/alert. |
| `alertSound()` | Play an alert sound notification. |

### Data Management

| Command | Description |
| :--- | :--- |
| `data` | Start of data definition lines. |
| `readData()` | Read file data. |
| `deleteData()` | Delete specified file data. |
| `moveData()` | Move or rename file data. |

### Output and Formatting

| Command | Description |
| :--- | :--- |
| `printHex()` | Output a value in Hexadecimal format. |
| `printBinary()` | Output a value in Binary format. |
| `dataType()` | Define data type (`textDocument`, `3DModel`, `2DSprite`, etc.). |
| `addDataType()` | Dynamically add a new custom data type. |
| `putText()` | Output/write a text string on the screen. |
| `putNum()` | Output/write numbers on the screen. |
| `hint()` | Provide a tooltip/hint for `putText` and `putNum`. |

### Data Types

3Dmodel, 2DSprite, textDocument, script, pythonScript, 3Dprefab, 2Dprefab, 3Dscene, 2Dscene, picturePNG, pictureJPG, videoMP4, videoMOV, musicMP3, musicOGG.
